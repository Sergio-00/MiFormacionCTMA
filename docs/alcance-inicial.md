# Alcance inicial · Mi Formación CTMA

## 1. Problema (máx. 120 palabras)

Los aprendices suelen manejar actividades, compromisos y evidencias en diferentes medios, lo que dificulta conocer qué tareas están pendientes, cuáles están por vencer y qué evidencias ya fueron realizadas. La aplicación **Mi Formación CTMA** busca ofrecer una forma para organizar actividades formativas, visualizar su estado de avance y facilitar el seguimiento del proceso académico desde un dispositivo móvil.

---

## 2. Tipos de usuario

### Aprendiz

**Necesidad:** consultar actividades pendientes y registrar evidencias de avance.

### Instructor

**Necesidad:** verificar el estado general de las actividades y revisar evidencias entregadas.

---

## 3. Historias de usuario

### Historia 1

**Como** aprendiz, **quiero** ver mis actividades pendientes **para** organizar mi tiempo de estudio.

**Criterio de aceptación:** al abrir la aplicación se muestra una lista de actividades pendientes.

---

### Historia 2

**Como** aprendiz, **quiero** identificar si una actividad está próxima a vencer **para** priorizar su realización.

**Criterio de aceptación:** una actividad con pocos días restantes se marca como urgente.

---

### Historia 3

**Como** instructor, **quiero** consultar el estado de avance de una actividad **para** realizar seguimiento del proceso formativo.

**Criterio de aceptación:** el sistema muestra el porcentaje de progreso asociado a la actividad.
