# Exploración del ecosistema Android

## Android Studio

IDE oficial para desarrollar aplicaciones Android.

## SDK

Conjunto de herramientas y las API necesarias para compilar y ejecutar aplicaciones.

## AVD

Dispositivo Android virtual utilizado para probar aplicaciones sin un teléfono físico.

## Gradle

Sistema de compilación y gestión de dependencias del proyecto.

## Jetpack Compose

Toolkit moderno para crear interfaces mediante funciones Kotlin llamadas `@Composable`.

## Logcat

Panel de registros que muestra errores, advertencias y mensajes de ejecución de la aplicación.
